# Copiloto de Feedback

Desafio 3 "O feedback que ninguém dá" — Rede Aurora, loja L004. Dados fictícios.

## Instalar as dependências

```bash
pip install -r requirements.txt
```

## Rodar

```bash
python -m uvicorn src.api:app --port 8000
```

Abra http://localhost:8000

Os 6 CSVs precisam estar em `dados/desafio-3-feedback/`.
